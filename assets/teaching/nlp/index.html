Assignments

Individual · auto-graded + short reflection · laptop-runnable (no GPU required)
A1

Tokenization & statistical LM

BPE, n-gram LM, perplexity per-token vs per-byte, GPT-2.
A2

Evaluation & error analysis

Precision/recall/F1, per-subgroup fairness, error taxonomy.
A3

Discriminative fine-tuning

Bag-of-words → embeddings → DistilBERT.
A4

Generative fine-tuning

Fine-tune GPT-2; canaries & a memorisation/extraction attack.
A5

Using the inference service

Batched client, latency sweep, token/compute budget.
A6 · optional

Probing & interpretability

Per-layer probes / attribution. Findings-only.

Group project briefs

Course-long group project (research & development) · 80% of the grade

GP Consultation Summaries (SOAP)

LLM summarisation + an LLM-as-judge benchmark + human-eval alignment.

flagship

RAG for Open-Domain Complex QA

Context-quality ablations in retrieval-augmented generation.

Characterising Toxicity in LLMs

Generate → score → attribution → lexical/syntactic analysis.

Model Leakage: attack & defend GPT-2

Membership-inference / extraction attacks and defences.

Timeline-based List QA

Closed-book vs RAG; temporal reasoning over lists.

Numerical & Temporal Fact Checking

Improve NLI veracity prediction + claim decomposition.

Knowledge Base Question Answering

Semantic-parsing + IR-based KBQA with pretrained models.
