Part I

Embeddings

Turning raw data types into dense, semantic vectors — unsupervised, automatic feature extraction.
How do we vectorize our input data?

The classic ML approach

The pipeline raw data (tabular · graph · text · …) → split into train / test → compute features → learning algorithm → model → output.
  • Every learner needs a vector, but raw data types don't come as vectors.
  • The hard question is the first step: how do we represent tabular, graph or text data as features?
  • Classic answer — hand-crafted features. The modern answer is embeddings.
Embeddings = unsupervised automatic feature extraction

From hand-crafted to learned features

Hand-crafted features

  • Sparse
  • Large (high-dimensional)
  • Non-semantic
  • Built by hand

Embeddings

  • Dense
  • Smaller (low-dimensional)
  • Semantic
  • Extracted automatically
An embedding is learned without labels, then reused as the input features for downstream supervised tasks.
High-dimensional → low-dimensional

Embeddings encode nodes (and words)

An encoder ENC(·) maps each node (or word) to a point so that similarity in the embedding space (e.g. a dot product zu·zv) approximates similarity in the context. High-dimensional features → a few semantic ones.

Part II

Graph Mining

Graph properties, centrality and clustering — read through the lens of matrices and eigendecompositions.
Graphs as matrices

Matrix representations & graph properties

From adjacency matrix we read… distance between nodes · eccentricity (farthest reachable) · radius (min eccentricity) · diameter (max eccentricity) · centrality measures.
The adjacency matrix A is symmetric for an undirected graph; row sums give node degree, and powers Ak count walks of length k.

Graph partitioning · the Fiedler vector

Spectral clustering: split by eigenvector sign

The second-smallest eigenvector of the Laplacian (the Fiedler vector). Sorting its entries, the sign of each component assigns nodes to group A (negative) or B (positive) — a principled graph bisection.
Girvan–Newman · centrality computation

Community detection by edge betweenness

  • Give each edge a credit = the credit that flows from parent → child in a breadth-first tree.
  • Summed over all source nodes, this is the edge's betweenness — how many shortest paths run through it.
  • Remove the highest-betweenness edge, recompute, and repeat; the graph falls apart into communities.
Two routes to clusters

Spectral clustering cuts using the Laplacian's eigenvectors; Girvan–Newman cuts by repeatedly deleting high-credit edges. Both turn a graph into groups.

Part III

Indexing Text

The data structures that let us search massive text collections fast — the inverted index and its dictionary.
The core structure

The inverted index

A lexicon (dictionary) of terms, each pointing to a postings list of the document IDs that contain it — e.g. is → 1, 3, 4, 5. Answering a query = intersecting / merging postings lists.
Data structures for indexing

Dictionary lookup & the forward index

Left: the dictionary as a hash table with collision chains, mapping a term to its ID. Right: a forward index — each document stored as its sequence of term IDs.

Summary

Take away

Embeddings turn raw data into dense, semantic vectors (unsupervised); graph mining reads structure through matrices, the Laplacian and eigendecompositions; indexing makes massive text searchable with inverted and forward indexes.

All three sit on the course spine — Distances · Matrices · Counting. Revise each as Concepts → Algorithms → Skills, and practise the worked examples by hand. Good luck on the exam.
